The two labels

Smaller than the card's own title, still unmistakably a header — the size goes down, the weight, capitals and letter-spacing go up:

font-size: 11px /* title is 14px */ font-weight: 600 letter-spacing: .06em text-transform: uppercase color: var(--text-tertiary)

11px is a deliberate step below the 14px title: at the same size the label competes with it, and at 10px or below it reads as metadata. Capitals plus tracking give it the authority the size gives up.

What changes, what does not

  • Changes: the two group labels, and one card per group.
  • Does not change: the main title and its plugin 26.10.7036 fact, every chip, the release/size/date line, the Download link, the stale-installer banner and the closing note.
  • One border per group rather than one per row, so the rows read as members of a group instead of as unrelated rows that happen to sit next to each other. Rows are separated by a hairline divider.
  • The grouping is quiet on purpose: no new colour on the latest release, because the Newest chip and the label already say it. A tinted variant is noted below.

Decisions this raises

  • "Earlier" on every row is now redundant — the group says it. Dropping it removes three chips that all say the same thing; keeping it costs nothing. Recommended: keep Latest Release's Newest chip, drop Earlier. The mockup keeps it, so the change under review is only the grouping.
  • One version only: today the whole card is hidden unless there are two or more versions, so a freshly deployed instance offers no installer download on this page at all. With a Latest Release group that no longer needs a history beside it, the card could show for a single version too. Shown in the second state; it is a behaviour change, not a layout one.
  • A tinted latest card (border and 6% cyan wash) is the heavier alternative if the grouping still reads as one list. Not the recommendation: the card already sits under a label and carries the Newest chip.
